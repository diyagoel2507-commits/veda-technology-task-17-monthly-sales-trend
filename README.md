## Project Overview
This project summarizes sales transactions month-wise for 2025 and visualizes the monthly sales trend using Microsoft Excel. The analysis focuses on date grouping, chronological month sorting, summary tables, and a line chart.

## Objectives
- Convert transaction dates into monthly groups.
- Calculate total sales for each month.
- Identify the highest and lowest sales months.
- Visualize monthly performance using a line chart.
- Practice Excel data summarization and trend analysis.

## Tools Used
- Microsoft Excel
- Pivot Table / SUMIF-based monthly summary
- Line Chart
